# Objetivos fisiológicos y evaluación de incertidumbre

El constructor interpola potencia o velocidad entre etapas medidas para objetivos de lactato o porcentaje de VO₂máx. Exige VO₂máx y etapas de VO₂ medidos para el segundo objetivo, y rechaza extrapolaciones, etapas insuficientes y curvas que no ofrecen una solución única. La duración se registra como prescripción: la interpolación de etapas no predice la cinética del VO₂ ni la sostenibilidad. Las plantillas contienen parámetros y nombre, se guardan en el navegador y se pueden reutilizar en otros tests de ese navegador; no se sincronizan entre dispositivos.

La sensibilidad aplica un desplazamiento sistemático positivo y negativo elegido por el usuario, a un tipo de medición a la vez. Incluye lactato, potencia, velocidad, VO₂ y VCO₂, según disponibilidad. Son escenarios, no intervalos de confianza ni una caracterización completa del error aleatorio, correlacionado, biológico o metodológico. Un escenario que impide calcular un resultado se informa como no disponible.

La comparación permite introducir una referencia individual independiente y, por separado, datos pareados anónimos para calcular sesgo y límites aproximados de concordancia. Las referencias deben utilizar unidades y protocolos comparables; definir límites aceptables previamente, revisar supuestos y tamaño de muestra. Los datos ingresados permanecen en memoria de la sesión y no se guardan. El software sigue sin validación externa: no hay una cohorte de referencia aportada en este cambio.
